webcool

文酷 — 你的私有文件，随时在手边

Your Private Files, Always Within Reach

webcool（文酷）是面向个人与私有环境的全能文件管理控制台：浏览器端管理远程与本地磁盘， iOS / Android 原生移动端随时访问；统一 REST API 协作，支持标签组织、多媒体预览、 手机相册备份、视频转码、视频投屏与局域网自动发现服务器。

webcool is an all-in-one file management console for private environments — a full browser console plus native iOS/Android mobile apps. Unified REST API for disk management, tags, media preview, phone album backup, video transcoding, video casting, and LAN server discovery.

Dual Disk Management

Virtual disk for uploads, local disk for server filesystem — both with list and split views.

标签树

Tag Tree

跨目录按主题组织，支持子标签、批量加标签；标签视图删除仅解除引用，图片标签可预览模式浏览。

Cross-directory topic organization, sub-tags, batch tagging; tag-view delete only removes references.

多媒体预览

Media Preview

图片、视频、音频、PDF、文本、Markdown 在线打开；视频续播，图片可旋转剪切编辑并保存。

Images, video, audio, PDF, text, Markdown online; video resume, image rotate/crop/edit & save.

上传与转码

Upload & Transcode

最多 50 文件同时上传，拖拽到目录树或上传区；上传后自动探测编码，不兼容则 ffmpeg 转码并显示进度。

Up to 50 files at once, drag to tree or drop zone; auto codec detection, ffmpeg transcode with progress.

🔐

加锁体系

Lock System

目录、文件、标签均可加锁，继承式目录锁；前后端双重校验，改名同步更新锁与标签信息。

Lock dirs, files, tags with inheritable dir locks; frontend + backend validation, rename syncs lock data.

Multi backup paths, upload auto-sync, manual backup sync; storage path change requires migration confirm.

Remote files to webcool recycle bin, local dirs to system trash; batch restore or permanent delete.

移动端相册备份 · 三种同步方式

Mobile Album Backup · Three Sync Modes

增量同步 Incremental

仅上传上次同步后的新照片与视频，节省流量与时间，适合日常自动备份。

Upload only new photos & videos since last sync — ideal for everyday backup.

重新同步 Full Resync

清除同步检查点，从相册开头重新扫描并上传，适合更换目录或需要全量重传时。

Reset checkpoint and re-upload from scratch — for folder changes or full redo.

按日期同步 Sync by Date

指定起始日期，仅同步该时间点之后的媒体；可按年/月/日格式自动归档到服务端目录。

Pick a start date to sync media after that point; auto-archive into year/month/day folders.

快速开始 Quick Start

三步搭建你的私有文件空间

Three Steps to Your Private File Space

安装 webcool 服务端、浏览器完成初始配置、手机安装移动端连接 — 全程可在局域网内完成。

Install webcool server, finish browser setup, connect the mobile app on your phone — all within your LAN.

1

安装 webcool 服务端

Install the webcool Server

从 下载页 获取对应平台安装包（macOS / deb / rpm / Windows），或手动部署二进制。安装包自包含 ffmpeg 与 sqlite。

Get the platform installer from the download page (macOS / deb / rpm / Windows) or deploy manually. Installers bundle ffmpeg & sqlite.

webcool -s 0.0.0.0:8080 -d ./uploads
2

浏览器首次配置

Browser First Setup

打开 Web 控制台，创建管理员账号；在系统设置中配置存储路径、备份与语言偏好。

Open the web console, create admin account; configure storage, backup & language in system settings.

http://<server-ip>:8080
3

安装 webcool 移动端

Install webcool Mobile

在 iPhone 或 Android 安装 webcool 移动端，连接服务器后可同步相册、浏览文件，或使用局域网扫描自动发现。

Install webcool mobile on iPhone or Android; connect to your server, sync albums, browse files, or use LAN scan to auto-discover.

http://192.168.x.x:8080
运维提示：使用 webcool -V 查看版本、存储路径、ffmpeg 等运行信息。macOS 默认数据目录 ~/Library/Application Support/webcool/data；Windows 默认 C:\ProgramData\webcool\uploads。 Ops tip: Run webcool -V for version, paths, ffmpeg, etc. Default data: macOS ~/Library/Application Support/webcool/data; Windows C:\ProgramData\webcool\uploads.
