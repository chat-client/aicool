关于 webcool

About webcool

webcool（文酷）是面向个人与私有环境的全能文件管理生态，包含浏览器控制台与 iOS / Android 移动端。 产品基于 acl 高性能网络框架构建，帮助用户在自托管环境中安全、高效地管理文件与媒体资源。

webcool is an all-in-one private file management ecosystem — a browser console plus iOS/Android mobile apps. Built on the high-performance acl networking framework, it helps you manage files and media securely on your own infrastructure.

我们在做什么

What We Build

webcool 提供虚拟磁盘与本地磁盘双模式管理、标签组织、多媒体预览、视频转码、备份迁移、 加锁保护等完整能力；移动端支持相册增量备份、局域网发现与视频投屏。

webcool delivers virtual and local disk management, tag organization, media preview, video transcoding, backup migration, and lock protection — with mobile album backup, LAN discovery, and video casting.

服务端支持 macOS、Linux 与 Windows 安装部署，数据完全掌握在你自己的服务器与私有网络中。

The server runs on macOS, Linux, and Windows — your data stays on your own servers and private network.

设计理念

Design Philosophy

轻量但不简陋 — 不满足于简单的上传下载，而是把文件管理、媒体消费、安全保护与长期运维衔接为完整体验。

Lightweight, not basic — more than upload/download, connecting file management, media use, security, and long-term operations.

自托管、数据自主、跨平台访问，让家庭服务器、工作站与私有云成为真正可用的个人文件中心。

Self-hosted, data sovereignty, cross-platform access — turning home servers, workstations, and private clouds into practical personal file hubs.
